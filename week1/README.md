# 🍽️ Random Lunch Menu Generator

Tired of deciding what to eat for lunch? This web app randomly generates a lunch idea for you with one click.

## ✨ Features

- **Randomized Selection** — a random lunch suggestion per click
- **Visual Appeal** — dish icons via Font Awesome 6.4.0 Free (solid), all icon classes verified to exist in the free set
- **Simple & Fast** — single static page, no dependencies beyond the FA CDN
- **Mobile-Friendly** — responsive layout

## 🚀 Live Demo

[LIVE DEMO](https://YuliaVodopyanova.github.io/LLM4Rec/week1/)

## 🛠️ How It Works

1. The app starts with a predefined list of dishes, each stored as a `{name, icon}` pair.
2. You click the "Generate Lunch!" button.
3. JavaScript picks a random entry from the list.
4. The dish name and its icon fade in after a short loading animation.

## 🧩 Installation & Local Development

1. Clone the repository (or download the `week1/` folder).
2. Open `week1/index.html` in your browser — no build step required.

## 🎯 How to Use

1. Open the page in your browser.
2. Click the "Generate Lunch!" button.
3. A random dish appears on screen.
4. Click again to re-roll and get a new suggestion.
